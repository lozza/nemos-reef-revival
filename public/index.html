About the project

Nemo's Reef Revival is a fan-made server for the Android version of Nemo's Reef. You host it at home and connect your copy of the game over your home network.

It supports saved reefs, buying and placing fish and plants, story quests, and visiting friends on the same server.

Still in development

Some features are unfinished, and there will be bugs. Co-op quests aren't supported yet. Back up your reef before updating.
